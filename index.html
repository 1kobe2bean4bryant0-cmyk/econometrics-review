重点1：对数模型与参数解释

📖 第2章(简单回归)、第4章(多元回归分析：推断)

📌 核心内容
双对数模型中斜率参数表示弹性；半对数模型中参数表示增长率或半弹性。Cobb-Douglas生产函数经对数变换后，截距项与原模型中效率参数 $A$ 的关系为 $\hat{A}=e^{\hat{\beta}_{0}}$。
📖 零基础一步一步学
第一步：先从「回归」说起（如果你忘了）
回归就是找一条线，描述 X 和 Y 的关系。比如工资(Y) 和 教育年数(X) —— 读的书越多，工资越高。回归方程就是写出来这个关系：Y = a + bX。这里的 b 告诉我们「X每增加1个单位，Y增加b个单位」。这是最基础的。
第二步：为什么有时候要用「对数」？
对数(ln)是一个数学工具，把大的数字变小。比如：ln(100)=4.6，ln(1000)=6.9。用对数有三个好处：
① 把乘法关系变成加法关系（更好计算）
② 结果可以直接看成「百分比变化」（更容易理解）
③ 数据会变得更整齐（减少异方差问题，后面会讲）
第三步：关键概念——「弹性」
弹性 = X变化1%时，Y变化百分之几。比如收入弹性=0.5，意思是：收入增加1%，消费增加0.5%。
注意：弹性和普通系数的区别：普通系数是「X变1单位，Y变多少」；弹性是「X变1%，Y变百分之几」。
第四步：第一种模型——双对数模型（lnY对lnX）
形式：lnY = a + b·lnX。此时 b 就是弹性。
例子：ln(销售额) = 3.2 + 0.45×ln(广告费)。b=0.45 的意思是：广告费增加1%，销售额增加0.45%。
为什么？因为两边都是对数，系数的解释自动变成「百分比对百分比」，这就是弹性。
第五步：第二种模型——半对数模型（lnY对X）
形式：lnY = a + b·X。此时 b×100% 就是增长率。
例子：ln(工资) = 0.584 + 0.083×教育年数。b=0.083，意思是：教育每多1年，工资增长8.3%。
为什么乘以100%？因为左边是对数(lnY)，右边是普通数字(X)，系数要×100%才是百分比变化。
第六步：举个例子一步一步算
假设 ln(工资) = 0.584 + 0.083×教育年数
问：教育从12年到16年，工资变了百分之几？
答：①先算Δln(工资)=0.083×(16-12)=0.332
②这个0.332的意思是：ln(新工资)-ln(旧工资)=0.332
③百分比变化≈0.332×100%=33.2%
精确一点的话：e^0.332-1≈39.4%。但考试直接用0.332×100%就行。
第七步：Cobb-Douglas生产函数
Y = A·K^α·L^β 这是经济学一个著名公式。
Y=产出，K=资本，L=劳动。
取对数后变成：lnY = lnA + α·lnK + β·lnL
α和β就是弹性——α=0.5表示资本增加1%，产出增加0.5%。
常数A=e^{截距}。比如截距=1.845，则A=e^1.845≈6.33。

📝 1.1 工资方程

$$\ln (wage)=0.584+0.083 educ +0.036 exper +0.003 exper ^{2}$$

重点2：虚拟变量与结构变化

📖 第7章(含有定性信息的多元回归分析：二值变量)

📌 核心内容
虚拟变量用于捕捉不同组别间的截距差异(加法形式)或斜率差异(交互项形式)。同时加入加法项和乘法项可同时反映截距和斜率的差异。
📖 零基础一步一步学
第一步：什么是「虚拟变量」？
虚拟变量 = 只能取0或1的变量。用来表示「是」或「不是」——比如：女性=1，男性=0。或者城市=1，农村=0。就这么简单。
第二步：为什么需要虚拟变量？
因为有些重要信息是「分类」的，不是数字。比如性别——你不能说「女性=2，男性=5」。只能说是或不是。所以要造一个0/1变量来代表它。
第三步：加法形式——只看截距差异
模型：Y = a + b×D + c×X
其中D是虚拟变量(0或1)。
当D=0(比如男性)：Y = a + cX
当D=1(比如女性)：Y = (a+b) + cX
b代表两组之间的差距。
如果b=-2，意味着女性平均比男性低2个单位。
第四步：交互项——看斜率差异
有时候不仅起点不同，变化速度也不同。
模型：Y = a + b×D + c×X + d×(D×X)
这里D×X是交互项。
当D=0：Y = a + cX（男性：教育每多1年，工资增加c）
当D=1：Y = (a+b) + (c+d)X（女性：教育每多1年，工资增加c+d）
如果d=0.01，说明女性每多读1年书的收益比男性高0.01。
第五步：一个具体例子帮助理解
模型：工资 = β₀ + β₁×女性 + β₂×教育 + β₃×(女性×教育)
假设β₀=10，β₁=-2，β₂=0.5，β₃=0.1
男性工资 = 10 + 0.5×教育
女性工资 = (10-2) + (0.5+0.1)×教育 = 8 + 0.6×教育
意思是：女性起薪比男性低2万(截距)，但每多读1年书，工资涨得比男性多0.1万(斜率)。
第六步：怎么检验「有没有差异」？
用t检验看β₁和β₃是否显著（不等于0）。
如果β₁显著→截距有差异（起薪不同）
如果β₃显著→斜率有差异（回报率不同）
如果都不显著→男女没有差别。

重点3：多重共线性诊断与处理

📖 第3章补充、第9章

📌 核心内容
方差膨胀因子 $VIF_{j}=1/(1-R_{j}^{2})$，$VIF>10$（或5）认为存在严重多重共线性。危害：参数估计方差增大、t统计量变小、系数符号可能反常，但$R^{2}$仍可能很高。处理方法：增样本、删变量、主成分、岭回归。
📖 零基础一步一步学
第一步：先理解「相关」
如果两个东西有关系，比如「房子面积」和「房间数量」——大房子通常房间多。这两个变量就是相关的。在回归里如果两个变量高度相关，就会出问题。
第二步：什么是多重共线性？
就是两个解释变量(比如房间数和卧室数)高度相关。模型没办法分清——工资上涨到底是因为房间数多了，还是卧室数多了？
就像你让两个人同时告诉你一个方向，他俩说的差不多，你听不清谁说的。
第三步：它会造成什么问题？
① 系数的标准误会变大（变得不确定）
② t值变小（本来显著的变量变得不显著）
③ 但整个方程的决定系数R²还是很高
这种情况让人很困惑：整体看模型很好(R²高)，但每个变量都不显著(t值小)。
第四步：怎么发现它？——VIF
VIF = 方差膨胀因子。公式：VIF = 1/(1-R²_j)
其中R²_j是把第j个变量对其他所有变量做回归得到的R²。
判断标准：VIF>10 → 严重多重共线性；VIF>5 → 需要关注。
算起来也不难——比如VIF=12.5，说明这个变量的方差因为共线性膨胀了12.5倍。
第五步：怎么处理？
① 删变量：把VIF最高的那个变量删掉。最简单但可能丢失信息。
② 增样本：拿更多数据。最理想但可能做不到。
③ 主成分分析/岭回归：更复杂的方法。了解有这回事就行。

📝 3.1 VIF诊断

$$VIF_{1}=18.5,\ VIF_{2}=12.3,\ VIF_{3}=2.1$$

(1) 是否严重？
步骤1[规则]VIF>10为严重多重共线性
步骤2[检查]VIF₁=18.5>10✓ VIF₂=12.3>10✓ VIF₃=2.1<10✗
步骤3[结论]变量1和2严重共线性，变量3正常
(2) 哪个根源？
步骤1[比较]VIF₁=18.5最大
步骤2[结论]变量1最可能是共线性根源
(3) 两种方案
步骤1[方案A]删VIF最高变量——简单但可能遗漏重要变量
步骤2[方案B]增加样本量——保留所有变量但可能无法获取

重点4：异方差性检验与处理

📖 第8章(异方差性)

📌 核心内容
异方差导致OLS估计量仍无偏但非有效，标准误估计有偏，t检验和F检验失效。检验方法：Breusch-Pagan检验、White检验。处理方法：加权最小二乘法(WLS)、异方差稳健标准误(HC标准误)。
📖 零基础一步一步学
第一步：先理解「方差」
方差衡量数据的分散程度。比如低收入人群的消费差异较小，高收入人群的消费差异很大——有人存钱有人花钱。
第二步：什么是「同方差」？
同方差 = 不管X怎么变，误差的波动幅度是一样的。
画个图：你沿着回归线走，误差项(点到线的距离)的分散程度始终一样。
这是OLS回归的理想状态。
第三步：什么是「异方差」？
异方差 = 误差的波动幅度会变。
比如研究储蓄和收入的关系——低收入者储蓄差异小(都没钱存)，高收入者储蓄差异大(有人存有人花)。
画出来像一个喇叭：X越大，残差越散开。
第四步：异方差有什么后果？
① 系数估计还是准的(无偏性的不受影响)
② 但标准误不准了——t检验、p值、置信区间全都不可信
③ 因为标准误错了，你没法判断系数是否显著
也就是说：你算出来的「显著性」可能是假的。
第五步：怎么发现异方差？
① 看图：把残差(实际值-预测值)画在图上。如果呈喇叭形散开→异方差。
② Breusch-Pagan检验：把残差的平方对X做回归，看R²。LM=n×R²。如果LM大于卡方临界值→存在异方差。
③ White检验：比BP检验更一般，加入了平方项和交叉项。
第六步：怎么处理？
① 稳健标准误(HC标准误)：不改变系数，只矫正标准误。最简单的办法。
② WLS(加权最小二乘)：给波动大的数据更小的权重。需要知道异方差的形式。
实际中最常用的是稳健标准误——大部分统计软件默认就有。

📝 4.2 Breusch-Pagan检验

$\hat{u}_{i}^{2}=\delta_{0}+\delta_{1} x_{1 i}+\delta_{2} x_{2 i}+v_{i}$，$R^{2}=0.18$，$n=100$

(1) 原假设和备择假设
步骤1[H₀]δ₁=δ₂=0(同方差)
步骤2[H₁]至少一个δ≠0(异方差)
(2) LM统计量
步骤1[公式]LM=n×R²(辅助回归)
步骤2[代入]LM=100×0.18=18
步骤3[临界值]χ²(2)在5%水平≈5.99
步骤4[判断]18>5.99→拒绝H₀→存在异方差
(3) 怎么处理？
步骤1[方法一]异方差稳健标准误(HC)——最常用
步骤2[方法二]WLS——需知道异方差具体形式

📝 4.3 CEO薪酬

$Var(u|sales,roe)=\sigma^{2}\cdot sales^{2}$

已知异方差形式

(1) 写出变换后模型
步骤1[原模型]y=β₀+β₁sales+β₂roe+u，Var(u)=σ²·sales²
步骤2[变换]两边÷sales→y/sales=β₀/sales+β₁+β₂(roe/sales)+u/sales

步骤2[权重]wt=1/sales²

步骤1[方法]使用异方差稳健标准误(HC标准误)

重点5：序列相关(自相关)检验与处理

📖 第12章(时间序列回归中的序列相关和异方差)

📌 核心内容
D.W.检验用于一阶自相关检验，$d \approx2(1-\hat{\rho})$。$dd_{U}$→不存在。序列相关导致OLS标准误有偏，t和F检验失效。处理方法：Cochrane-Orcutt迭代、Newey-West标准误。
📖 零基础一步一步学
第一步：什么是「时间序列」？
时间序列 = 按时间顺序排列的数据。比如每天的股价、每年的GDP。跟横截面数据(同一时间点调查很多人)不同，时间序列数据前后有关联。
第二步：什么是「自相关」？
自相关 = 今天的误差和昨天的误差有关系。
比如今年GDP高了→明年可能也高(经济有惯性)。
这就是正自相关——今天高明天也高。
第三步：自相关的后果
和异方差类似：系数估计还是准的，但标准误不准→t检验失效。
如果存在正自相关(最常见)，OLS标准误会被低估，让你觉得系数显著但实际上可能不显著。
第四步：怎么发现？——DW检验
DW统计量≈2×(1-ρ̂)。ρ是自相关系数。
判断规则：
· DW≈2 → 无自相关
· DW明显小于2(如0.85) → 正自相关
· DW明显大于2(如3.2) → 负自相关
有两个临界值dL和dU：DWdU→无；在中间→无法判断。
第五步：怎么处理
① Cochrane-Orcutt迭代法：先估计ρ，然后用ρ变换数据，消除自相关。
② Newey-West标准误：直接矫正标准误，不改变系数。更简单。
在实际应用中，Newey-West标准误更常用。

📝 5.1 DW检验

$y_{t}=\beta_{0}+\beta_{1} x_{t}+u_{t}$，n=50，DW=1.35，dL=1.32，dU=1.53

(1) 是否存在自相关？
步骤1[规则]DWdU→无；中间→无法判断
步骤2[代入]dL=1.32
步骤3[结论]落在无法判断区域(inconclusive)
(2) 标准误怎么变？
步骤1[结果]若ρ>0(正自相关)→OLS标准误被低估(偏小)
步骤2[影响]t统计量被高估→可能错误认为系数显著
(3) Cochrane-Orcutt第一步方程
步骤1[估计ρ]ρ̂≈1-DW/2=1-1.35/2=0.325
步骤2[变换]y_t-0.325y_{t-1}=β₀(1-0.325)+β₁(x_t-0.325x_{t-1})+e_t
步骤3[目的]变换后消除自相关

📝 5.2 季度数据

$DW=0.85$，n=60，dL=1.55，dU=1.62

(1) 判断自相关
步骤1[比较]DW=0.85
步骤2[判断]存在一阶正自相关
步骤3[严重度]DW=0.85远小于2→自相关较严重
(2) ρ的值
步骤1[公式]ρ̂≈1-DW/2
步骤2[代入]ρ̂=1-0.85/2=0.575
步骤3[含义]当期误差与上期误差正相关性较强
(3) Newey-West优势
步骤1[OLS]存在自相关时OLS标准误有偏
步骤2[NW]Newey-West标准误在自相关+异方差同时存在时仍保持一致(稳健)

📝 5.3 含滞后因变量模型

$$y_{t}=\beta_{0}+\beta_{1} y_{t-1}+\beta_{2} x_{t}+u_{t}$$

(1) DW是否适用？
步骤1[原因]模型包含滞后因变量y_{t-1}
步骤2[后果]DW检验偏向不拒绝H₀，检验失效
(2) 若u_t=ρu_{t-1}，OLS一致吗？
步骤1[推导]y_{t-1}与u_{t-1}相关，u_t与u_{t-1}相关→y_{t-1}与u_t相关
步骤2[结论]违反外生性假设→OLS不一致
(3) 适用方法
步骤1[方法一]Durbin h检验(适用于含滞后因变量)
步骤2[方法二]Breusch-Godfrey LM检验

重点6：F检验与回归显著性检验

📖 第4章(多元回归分析：推断)

📌 核心内容
回归总体显著性F统计量：$F=\frac{ESS/k}{RSS/(n-k-1)}=\frac{R^{2}/k}{(1-R^{2})/(n-k-1)}$，用于检验所有斜率系数同时为零。区别于单个参数的t检验。
📖 零基础一步一步学
第一步：F检验是做什么的？
t检验是看一个变量是否显著；F验是看所有变量一起是否显著。
打个比方：t检验是「逐个面试」，F检验是「群面」——你一个人好不好不重要，你们整个团队好不好才重要。
第二步：F统计量的公式
F = (R²/k) / [(1-R²)/(n-k-1)]
其中：
· R² = 模型能解释的百分比
· k = 解释变量的个数
· n = 样本量
F值越大→模型越显著。
第三步：怎么判断是否显著？
查F分布表。给定显著性水平(通常是5%)和自由度(k, n-k-1)，有一个临界值。如果F大于这个临界值→回归显著。
比如F=95，而临界值≈2.70，95>>2.70→高度显著。
第四步：F检验的两种应用
① 总体显著性：检验所有变量一起是否对Y有影响(H₀:所有系数=0)。
② 约束检验：检验某一个条件是否成立。比如检验β₁=β₂，或α+β=1。用有约束和无约束的RSS来计算F。
第五步：F和t的关系
· F显著但个别t不显著→可能有多重共线性（整体有意义但单个变量分不清）
· 反过来，F不显著但个别t显著→很少见，可能是数据问题
· F检验比t检验更「整体」

📝 6.1 多元回归显著性

$Y=\beta_{0}+\beta_{1} X_{1}+\beta_{2} X_{2}+\beta_{3} X_{3}+u$，n=100，ESS=450，RSS=150

(1) R²和调整R̄²
步骤1[R²]R²=ESS/(ESS+RSS)=450/(450+150)=450/600=0.75
步骤2[R̄²]R̄²=1-(1-R²)(n-1)/(n-k-1)=1-0.25×99/95=1-0.2605≈0.7395
。
(2) 总体显著性检验
步骤1[公式]F=(R²/k)/[(1-R²)/(n-k-1)]
步骤2[代入]F=(0.75/3)/(0.25/95)=0.25/0.002632≈95
步骤3[临界]F₀.₀₅(3,95)≈2.70
步骤4[判断]95>2.70→拒绝H₀→回归高度显著
(3) F和t的区别
步骤1[F检验]所有斜率系数是否全为零(联合检验)
步骤2[t检验]单个系数是否为零(个体检验)
步骤3[关系]F显著但个别t不显著→可能多重共线性

📝 6.2 约束检验

$RSS_U=120$，$RSS_R=135$，n=50，k=4。检验β₁=β₂

(1) 原假设
步骤1[H₀]β₁=β₂(一个约束条件，q=1)
步骤2[H₁]β₁≠β₂
(2) F统计量
步骤1[公式]F=[(RSS_R-RSS_U)/q]/[RSS_U/(n-k-1)]
步骤2[代入]F=[(135-120)/1]/[120/(50-4-1)]=15/[120/45]
步骤3[计算]=15/2.6667≈5.62
(3) 5%水平下
步骤1[临界值]F₀.₀₅(1,45)≈4.06
步骤2[比较]5.62>4.06→拒绝H₀
步骤3[结论]β₁≠β₂，加入约束后RSS显著增大

📝 6.3 R²与F

$R²=0.72$，n=35，k=5

(1) 计算F
步骤1[公式]F=(R²/k)/[(1-R²)/(n-k-1)]
步骤2[代入]F=(0.72/5)/[(1-0.72)/(35-5-1)]
步骤3[计算]=0.144/[0.28/29]=0.144/0.009655≈14.91
(2) 所有t不显著但F显著？
步骤1[原因]多重共线性导致变量标准误增大→t变小
步骤2[整体]但模型整体有意义→F显著
(3) 与共线性的关系
步骤1[结论]R²高(F统计量大)但单个变量t值小→多重共线性的典型症状

重点7：随机误差项与残差

📖 第2章(简单回归)

📌 核心内容
随机误差项 $u_{i}$ 是总体模型中不可观测的随机变量；残差 $\hat{u}_{i}=Y_{i}-\hat{Y}_{i}$ 是样本估计值。残差是误差项的样本对应物；误差项不可观测，残差可计算；OLS下残差和为0，但误差项均值为0是假设。
📖 零基础一步一步学
第一步：先回想一下回归模型
Y = a + bX + u
Y = 实际值（你看到的数据）
a+bX = 预测值（回归线告诉你的）
u = 误差项（实际值和预测值的差距）
第二步：什么是误差项u？
u是「真实的误差」——实际值减去真实回归线的差距。
但有一个问题：真实回归线我们永远不知道！因为我们只有样本数据。
所以u是不可观测的。我们只能假设它的平均值是0（E(u)=0）。
第三步：什么是残差û？
û = 实际值 - 我们估计的回归线
这个是可以算出来的——因为我们的回归线是知道的。
残差 = 实际值 - 预测值。就这么简单。
第四步：两者的关键区别
误差项u = 真值 - 真实回归线（永远不知道）
残差û = 真值 - 估计回归线（可以计算）
残差是误差项的「估计」——我们用û来推测u。
第五步：一个总搞混的点
E(u)=0是假设（我们认为平均误差为0）
∑û=0是数学结果（OLS自动让残差和为零）
初学者常犯的错误：说「因为E(u)=0，所以残差和为零是自然的」
不对！E(u)=0是假设，∑û=0是数学推导的结果。
第六步：残差有三个重要性质
① 残差和为零（∑ûᵢ=0）
② 残差和X不相关（∑Xᵢûᵢ=0）
③ 残差的均值就是预测值的均值
这些都是OLS自动保证的。

📝 7.1 u与û的定义

总体模型$Y_{i}=\beta_{0}+\beta_{1} X_{i}+u_{i}$，样本回归$\hat{Y}_{i}=\hat{\beta}_{0}+\hat{\beta}_{1} X_{i}$

(1) 写出u_i和û_i
步骤1[u_i]u_i=Y_i-(β₀+β₁X_i)——总体回归误差，不可观测
步骤2[û_i]û_i=Y_i-(β̂₀+β̂₁X_i)=Y_i-Ŷ_i——样本残差，可计算
(2) 证明∑û_i=0
步骤1[条件]∂RSS/∂β̂₀=-2∑(Y_i-β̂₀-β̂₁X_i)=0
步骤2[推导]-2∑û_i=0→∑û_i=0
步骤3[结论]残差和为零是OLS数学推导结果
(3) 为什么∑u_i=0不一定成立？
步骤1[原因]E(u)=0是理论假设
步骤2[关键]假设≠样本中实际成立，且u_i不可观测无法验证

📝 7.2 混淆概念

有人认为「因为E(u)=0，残差和必为零是自然的」

(1) 指出问题
步骤1[错误]混淆了总体误差项u(不可观测)和样本残差û(可计算)
步骤2[澄清]E(u)=0是理论假设；∑û=0是OLS数学性质
(2) 解释为何是OLS结果
步骤1[推导]∂RSS/∂β̂₀=0→∑û_i=0
步骤2[来源]来自最小化残差平方和的数学运算
(3) û何时可近似u？
步骤1[条件1]样本量足够大
步骤2[条件2]模型设定正确(无遗漏变量)
步骤3[结论]此时残差是误差项的一致估计

📝 7.3 残差与X不相关

证明∑X_iû_i=0

(1) 证明
步骤1[条件]∂RSS/∂β̂₁=-2∑X_i(Y_i-β̂₀-β̂₁X_i)=0
步骤2[代入]Y_i-β̂₀-β̂₁X_i=û_i→-2∑X_iû_i=0→∑X_iû_i=0
(2) 与E(u|X)=0的关系
步骤1[∑Xû=0]OLS代数结果——计算上必然成立
步骤2[E=0]E(u|X)=0是总体假设——保证无偏性
(3) 遗漏变量时还成立吗？
步骤1[计算上]OLS计算性质仍保证∑X_iû_i=0
步骤2[意义上]但残差包含了遗漏变量效应，不能再近似为u

重点8：Probit与Logit模型

📖 第17章(限值因变量模型和样本选择纠正)

📌 核心内容
二元离散选择模型(Y=0或1)。Probit使用标准正态CDF，Logit使用逻辑斯蒂CDF。边际效应≠系数本身，需通过链式法则：$\partial P/\partial x_j =\beta_j \cdot g(\beta_0+\beta_1 x_1+\cdots)$，g为PDF。
📖 零基础一步一步学
⚠️ 战略放弃提示
本章是进阶内容，如果你的目标是考过且老师会捞，建议优先学好前7章。时间允许再看这里。
第一步：什么时候用Probit/Logit？
当Y只能取0或1的时候——比如：是否贷款批准？是否参加工作？
普通回归(OLS)不适合，因为预测值会超出0-1范围。
第二步：Probit和Logit的区别
两者几乎一样，只是用不同的数学函数：
Probit用标准正态分布(像钟形曲线)
Logit用逻辑分布(形状类似但尾巴更厚)
结果通常差异很小。
第三步：关键提醒——系数≠边际效应
在普通回归中，系数就是「X增1单位Y增b」。但在这里不是！
因为模型是非线性的，系数的解释需要通过一个转换才能变成概率的变化。
考试中如果是选择题，记住「系数不能直接解释为概率变化」就行。

📝 8.1 Logit贷款批准

$P(loan=1|income)=\Lambda(0.5+0.02\ income)$，$\Lambda(z)=e^{z}/(1+e^{z})$

income千元

(1) income=30时概率？
步骤1[计算z]z=0.5+0.02×30=1.1
步骤2[概率]P=e^1.1/(1+e^1.1)=3.004/4.004≈0.75
步骤3[结论]贷款批准概率约75%
(2) 30→31概率变化？
步骤1[公式]边际效应=β×P×(1-P)
步骤2[代入]0.02×0.75×0.25=0.00375
步骤3[结论]收入增1千元→贷款概率增约0.375个百分点
(3) 0.02为什么不是边际效应？
步骤1[原因]Logit是非线性模型
步骤2[说明]0.02是潜变量系数，不是概率变化，需通过PDF转换

📝 8.2 Probit劳动参与

$P(inlf=1|educ,exper)=\Phi(-0.5+0.15\ educ+0.02\ exper)$

Φ标准正态CDF

(1) educ=12,exper=10时？
步骤1[计算z]z=-0.5+0.15×12+0.02×10=-0.5+1.8+0.2=1.5
步骤2[查表]Φ(1.5)≈0.9332
步骤3[结论]劳动参与概率约93.3%
(2) 教育边际效应
步骤1[公式]边际效应=β×φ(z)
步骤2[代入]0.15×0.1295≈0.0194
步骤3[结论]教育增1年→参与概率增1.94个百分点
(3) Probit vs Logit
步骤1[相同]都通过β×PDF计算边际效应
步骤2[不同]PDF不同(正态vs逻辑分布)，结果通常接近

📝 8.3 LPM缺陷

LPM得β̂₁=0.3，Logit得β̂₁=1.2

(1) LPM缺陷
步骤1[缺陷1]预测概率可能<0或>1
步骤2[缺陷2]误差必然异方差
步骤3[缺陷3]边际效应固定不变(不符合非线性)
(2) 能说Logit是4倍？
步骤1[原因]LPM的0.3是概率变化；Logit的1.2是潜变量系数
步骤2[结论]不能直接比较，Logit需先转换为边际效应
(3) 何时两者近似？
步骤1[条件1]预测概率在0.2-0.8之间
步骤2[条件2]Logit/Probit曲线接近直线时

重点9：多元线性回归的基本假设与OLS性质

📖 第2–3章

📌 核心内容
高斯-马尔可夫假设：线性于参数、随机抽样、解释变量变异、零条件均值(外生性)、同方差、无完全共线性。这些假设下OLS是BLUE(最佳线性无偏估计量)。无偏性用零条件均值假设；有效性用同方差假设。
📖 零基础一步一步学
第一步：复习一下回归在做的事情
回归就是找一条线：Y = β₀ + β₁X₁ + β₂X₂ + ... + u
我们要用样本数据估计出β₀, β₁, β₂...这些系数。
OLS是最常用的估计方法——它让残差的平方和最小。
第二步：为什么OLS需要假设？
就像做菜需要先准备好食材——没有食材做不了菜。没有假设，OLS的性质就得不到保证。
一共有六个高斯-马尔可夫假设（简称GM假设）。
第三步：六个假设（一个一个来）
① 线性于参数：模型写成Y=β₀+β₁X+u的形式，不能是Y=β₁²X这种。
② 随机抽样：样本是随机抽取的。
③ 解释变量有变异：X不能是常数（全是0或全是1没用）。
④ 零条件均值E(u|X)=0：误差和X没有关系——最重要的一条！
⑤ 同方差Var(u|X)=σ²：误差的波动幅度不变。
⑥ 无完全共线性：变量之间不完全是线性关系。
第四步：最重要的假设——E(u|X)=0
用大白话说：误差里不能有和X有关的东西。
举个例子：研究教育对工资的影响。误差里包含了「能力」。能力强的人工资高，受教育也多。所以教育就和误差(能力)相关了→E(u|X)≠0→OLS就不准了。
这叫内生性问题，需要用工具变量来解决。
第五步：BLUE是什么意思？
BLUE = Best Linear Unbiased Estimator（最佳线性无偏估计量）
· 无偏 = 平均而言估计值等于真实值
· 最佳 = 在所有无偏估计量中方差最小
在六个假设都成立的情况下，OLS就是BLUE。

📝 9.1 GM假设

$Y=X\beta+u$

(1) 六个GM假设
步骤1[假设1]线性于参数——模型写为Y=β₀+β₁X+u
步骤2[假设2]随机抽样——样本随机
步骤3[假设3]X有变异——X不是常数
步骤4[假设4]E(u|X)=0——零条件均值(最重要)
步骤5[假设5]同方差——Var(u|X)=σ²
步骤6[假设6]无完全共线性
(2) 哪个保证无偏性？
步骤1[答案]E(u|X)=0(零条件均值假设)
步骤2[理由]此假设使E(β̂|X)=β
(3) 哪个保证有效性？
步骤1[答案]同方差假设Var(u|X)=σ²
步骤2[理由]使OLS在所有无偏估计中方差最小
(4) E(u|X)≠0会怎样？
步骤1[后果]OLS有偏且不一致(内生性问题)
步骤2[解法]需工具变量法(2SLS)

📝 9.2 无偏性证明

$$\hat{\beta}_{1}=\frac{\sum(X_{i}-\bar{X})(Y_{i}-\bar{Y})}{\sum(X_{i}-\bar{X})^{2}}$$

(1) 代入Y写出E(β̂₁|X)
步骤1[代入]Y_i=β₀+β₁X_i+u_i→β̂₁=β₁+∑w_iu_i
步骤2[期望]E(β̂₁|X)=β₁+∑w_iE(u_i|X)
(2) E(u_i|X)=0的作用
步骤1[条件]若E(u_i|X)=0→∑w_iE(u_i|X)=0
步骤2[结果]E(β̂₁|X)=β₁→无偏性成立
(3) X与u相关结论？
步骤1[推导]E(u|X)≠0→E(β̂₁|X)≠β₁
步骤2[结论]OLS有偏

重点10：工具变量与内生性

📖 第15章(工具变量估计与两阶段最小二乘法)

📌 核心内容
解释变量与误差项相关(内生性)时OLS有偏且不一致。工具变量Z需：相关性(与内生解释变量相关)和外生性(与误差项不相关)。2SLS是处理多个内生变量和多个IV的通用方法。
📖 零基础一步一步学
⚠️ 战略放弃提示
本章也是进阶内容。如果时间紧，优先复习前7章。
第一步：什么是内生性？
简单说：X和误差u有关联了。
比如研究教育对工资的影响——能力强的人既受教育多又工资高。教育就和误差(能力)有关了。
这就叫内生性。OLS在这种情况下就不准了。
第二步：怎么解决？——工具变量Z
找一个变量Z，它满足两个条件：
① Z能影响X（相关性）
② Z不影响Y除了通过X（外生性）
比如用「家到最近大学的距离」作为教育的工具变量——离家近→更容易上大学→但不直接影响工资。
第三步：2SLS两步法
第一步：把X对Z做回归，得到X̂（排除掉X和u相关的部分）
第二步：用X̂代替X对Y做回归
这样得到的就是一致的估计。

📝 10.1 IV估计量

$Y_i=\beta_0+\beta_1X_i+u_i$，X与u相关，工具Z

(1) IV的两个条件
步骤1[条件1]相关性——Cov(Z,X)≠0
步骤2[条件2]外生性——Cov(Z,u)=0(靠逻辑论证)
(2) IV估计量表达式
步骤1[公式]β̂₁_IV=Cov(Z,Y)/Cov(Z,X)
步骤2[说明]分子是Z与Y的协方差，分母是Z与X的协方差
(3) 为什么Z与u不相关关键？
答：若相关则IV不一致。

📝 10.2 距离作为IV

用「到最近大学距离」作为教育IV

(1) 相关性满足吗？
答：可能满足——距大学近→上大学概率高。需要F检验。
(2) 外生性满足吗？
答：有争议——近大学地区经济发达可能直接影响工资。
(3) 写出2SLS
答：①educ=γ₀+γ₁dist+v ②ln(wage)=β₀+β₁eduĉ+u。

📝 10.3 F检验

y=β₀+β₁x₁+β₂x₂+u，x₂内生，z₁z₂为IV

(1) 第一阶段回归
答：x₂=γ₀+γ₁z₁+γ₂z₂+γ₃x₁+v。
(2) F检验作用
答：检验IV联合显著性。经验准则F>10。
(3) F=3.5说明什么？
答：F<10→弱工具变量。IV可能有偏。

重点11：面板数据模型

📖 第13–14章

📌 核心内容
面板数据兼具截面和时间维度，可控制不可观测的个体异质性。固定效应(FE)通过组内变换消除不随时间变化的个体效应；随机效应(RE)假设个体效应与解释变量不相关。Hausman检验选择FE与RE。
📖 零基础一步一步学
第一步：什么是面板数据？
面板数据 = 同一批对象(人/企业/国家)跟踪多年观察。
比如：100家企业，连续追踪5年，共500条数据。
好处：可以控制每个企业「天生不同」的那部分。
第二步：为什么要用面板？
每个人/企业都有自己的特点，这些特点可能是固定的。
比如有的公司管理好，有的公司地理位置好。
面板数据可以剔除这些固定特征，看到真正的原因。
第三步：固定效应(FE)
FE假设每个个体有自己的截距(个体效应aᵢ)，这个aᵢ可以和X相关。
FE通过「去均值」把aᵢ消掉——用每个变量减去它在时间上的平均值。
结果：aᵢ消失了，只留下随时间变化的部分。
第四步：随机效应(RE)
RE假设个体效应aᵢ和X不相关。
如果这个假设成立，RE比FE更有效(方差更小)。
但如果不成立，RE就有偏。
第五步：Hausman检验
用来决定用FE还是RE。
H₀：aᵢ与X不相关(RE可靠且有效)
如果Hausman检验显著(p<0.05)→拒绝H₀→用FE
如果不显著→可以用RE

📝 11.1 FE变换

$y_{it}=\beta_0+\beta_1x_{it}+a_i+u_{it}$

(1) 写出组内去均值模型
答：(y_{it}-\bar{y}_i)=β₁(x_{it}-\bar{x}_i)+(u_{it}-\bar{u}_i)。
(2) 证明a_i被消除
答：原式减时间均值→a_i消掉（因为a_i不随时间变）。
(3) FE能否估计不变变量？
答：不能。不随时间变的变量(如性别)会被差分掉。

📝 11.2 FE vs RE

企业面板估计生产函数

(1) RE假设
答：Cov(a_i,x_{it})=0。GLS加权重合组内和组间变异。
(2) Hausman检验逻辑
答：H₀:Cov(a_i,X)=0(RE一致)。显著→拒绝RE。
(3) 拒绝H₀选哪个？
答：选FE。RE有内生性时不一致。

📝 11.3 FD vs FE

$\Delta y_{it}=\beta_1\Delta x_{it}+\Delta u_{it}$

(1) FD与FE异同
答：同：都消除a_i。异：FD用一阶差分，FE用组内去均值。
(2) T=2时
答：FD与FE等价。
(3) 序列相关时谁更有效？
答：正自相关时FD更有效；白噪声时FE更有效。

重点12：时间序列与平稳性

📖 第10–11章

📌 核心内容
时间序列需关注平稳性。非平稳序列(如随机游走)可能导致伪回归。ADF检验判断是否平稳。协整允许对非平稳序列进行回归。
📖 零基础一步一步学
第一步：什么是平稳性？
平稳 = 数据的统计性质(均值、方差)不随时间变化。
比如白噪声(纯粹随机波动)就是平稳的——它没有趋势。
第二步：非平稳是什么样？
大多数经济指标是非平稳的——比如GDP、股价，一直在涨。
这些序列的均值随时间变化，所以不是平稳的。
随机游走是典型的非平稳序列：y_t = y_{t-1} + e_t。今天的值=昨天的值+一个随机波动。
第三步：伪回归是什么？
如果你把两个毫无关系的非平稳序列放在一起做回归——比如中国的GDP和美国的降雨量——可能得到一个高度显著的结果。
但这是假的！只是因为它们都有时间趋势，并不是真的有因果关系。
这就是伪回归。
第四步：怎么判断是否平稳？——ADF检验
原假设H₀：序列非平稳(有单位根)。
如果检验统计量小于临界值→拒绝H₀→序列平稳。
如果不拒绝→非平稳→需要差分。
第五步：协整——两个非平稳序列的关系
有时候两个非平稳序列(比如消费和收入)的某种组合是平稳的。
这意味着它们有长期均衡关系——虽然各自不平稳，但不会偏离太远。
这叫做协整。

📝 12.1 随机游走

$y_t=y_{t-1}+e_t$，$e_t\sim iid(0,\sigma^2)$

(1) 证明方差随时间递增
答：Var(y_t)=tσ²。t越大方差越大→非平稳。
(2) 为什么伪回归？
答：趋势使t值偏大R²偏高。Granger-Newbold证明了这一点。
(3) ADF检验方程
答：Δy_t=α+δt+γy_{t-1}+∑θ_jΔy_{t-j}+e_t。H₀:γ=0。

📝 12.2 协整

ln(GDP_t)和ln(消费_t)均为I(1)，线性组合平稳

(1) 协整含义
答：两个非平稳序列有长期均衡关系。
(2) ECM形式
答：ΔY_t=α+βΔX_t+γ(Y_{t-1}-δX_{t-1})+e_t。
(3) 误差修正项符号
答：γ<0(负值)。短期偏离时拉回均衡。

📝 12.3 ADF检验

$$\Delta y_t = \alpha + \delta t + \gamma y_{t-1} + \sum\theta_j\Delta y_{t-j} + e_t$$

检验统计量=-2.1，5%临界值=-3.5

(1) 假设
答：H₀:γ=0(非平稳)；H₁:γ<0(平稳)。
(2) 结论
答：-2.1 > -3.5→不拒绝H₀→非平稳。
(3) 滞后阶数选择
答：AIC或BIC。

重点13：模型设定与函数形式

📖 第6章、第9章

📌 核心内容
遗漏变量导致估计偏误(遗漏变量与包含变量相关时)；包含无关变量增大方差但不导致偏误。RESET检验用于检验函数形式误设。代理变量和测量误差也是重要数据问题。
📖 零基础一步一步学
第一步：遗漏变量偏误
真实情况：Y受X₁和X₂影响。但你只把X₁放进模型。
X₂被「遗漏」了——它跑到了误差项里。
如果X₁和X₂相关(比如教育和能力)，X₁的系数会吸收X₂的效应→有偏。
第二步：包含无关变量
反过来：你把一个没用的变量加进模型了。
后果：系数仍是无偏的（不会出大错），但方差会增大（估计不那么精确）。
所以不应该加不必要的变量。
第三步：RESET检验
怎么知道模型形式对不对？
在原模型中加入预测值的平方和立方项(Ŷ²和Ŷ³)，看它们是否显著。
如果显著→说明模型形式有问题，可能需要取对数或加平方项。
第四步：测量误差
如果X测不准（比如收入经常报低），X的系数会偏向0。
这叫衰减偏误——真实效应被低估了。
测量误差越大(相对于X本身的变异)，偏误越严重。

📝 13.1 遗漏变量偏误

真实$Y=\beta_0+\beta_1X_1+\beta_2X_2+u$，估计$Y=\alpha_0+\alpha_1X_1+v$

(1) plim(α̂₁)
答：plim(α̂₁)=β₁+β₂·δ，δ=Cov(X₁,X₂)/Var(X₁)。
(2) α̂₁何时无偏？
答：β₂=0或Cov(X₁,X₂)=0时。
(3) X₂=能力，X₁=教育
答：能力高教育也多(Cov>0)→α̂₁高估教育真实回报。

📝 13.2 RESET检验

(1) 基本思想
答：若函数正确，Ŷ的高次项不应有解释力。
(2) 辅助回归
答：y=β₀+β₁x+δ₁ŷ²+δ₂ŷ³+u，检验δ₁=δ₂=0。
(3) Ŷ²和Ŷ³显著
答：拒绝H₀→应考虑非线性形式。

📝 13.3 测量误差

观测到X*=X+e，e与X和u不相关

(1) 偏误方向
答：偏向0——测量误差削弱X与Y的关系。
(2) 衰减偏误
答：系数被拉向0。Var(e)/Var(X)越大偏误越重。
(3) 二值变量时？
答：分类错误也会导致偏误，方向不一定衰减。
