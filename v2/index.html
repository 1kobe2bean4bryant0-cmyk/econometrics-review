专题1：对数模型与参数解释（Logarithmic Models）

🔴 核心专题 ★★★★★

📖 第2章(简单回归)、第4章(多元回归分析：推断)

📌 核心内容
双对数模型中斜率参数表示弹性；半对数模型中参数表示增长率或半弹性。Cobb-Douglas函数取对数后，截距的指数为效率参数A。
🎯 考试权重：★★★☆☆（案例分析高频）

📖 第0节 · 学习前的准备
0.1 什么是回归方程？
计量最常见的工作：用原因预测结果。
公式：Y = β₀ + β₁X + u
· Y=结果(被解释变量) · X=原因(解释变量) · β₁=斜率：X↑1单位→Y平均变化β₁ · β₀=截距 · u=误差项
0.2 什么是自然对数ln？
① ln(A×B)=lnA+lnB（乘法变加法）　② ln(X^k)=k·lnX　③ 关键：ΔlnX ≈ ΔX/X（百分比变化）
ln(1.05)≈0.05=5%——对数的变化量≈原变量的百分比变化
0.3 什么时候该取对数？
· 变量是正数且右偏（如工资、收入）
· 想解释「百分比变化」而非「绝对变化」
· 变量之间可能是乘法关系（如Cobb-Douglas生产函数）

单选 判断 简答 案例 本节内容覆盖全部题型
1.1 双对数模型——系数是弹性 单选 案例
形式：lnY = β₀ + β₁lnX + u
β₁叫弹性：X变化1%，Y变化β₁%。
推导：ΔlnY≈β₁·ΔlnX，ΔlnY≈ΔY/Y，ΔX/X≈1%时ΔY/Y≈β₁·1%=β₁%。
简单记：两边都有ln → 百分比对百分比
1.2 半对数模型(A)——lnY对X 单选 判断 简答
形式：lnY = β₀ + β₁X + u
β₁×100%叫半弹性：X↑1单位→Y变化约(β₁×100)%。
例子：ln(工资)=0.584+0.083×educ → 多读1年书工资增约8.3%
⚠ 精确公式：%ΔY=100×[exp(β₁ΔX)-1]
1.3 半对数模型(B)——Y对lnX 单选 判断
形式：Y = β₀ + β₁lnX + u
β₁/100的含义：X变化1%，Y变化β₁/100个单位。
1.4 Cobb-Douglas生产函数变换 简答 案例
原始：Y = A·K^α·L^β·e^u → lnY=lnA+αlnK+βlnL+u
α=资本弹性，β=劳动弹性。Â = e^{截距}

⚠ 易混淆辨析：对数模型形式

概念A概念B核心区别
lnY = β₀ + β₁lnX + u双对数模型系数β₁=弹性：%对%
lnY = β₀ + β₁X + u半对数模型(A)系数β₁×100%=增长率：单位对%
Y = β₀ + β₁lnX + u半对数模型(B)系数β₁/100=半弹性：%对单位

2.1 虚拟变量的基本概念与设置原则

📝 题型覆盖 单选判断简答案例

2.1.1 虚拟变量的定义

单选判断

虚拟变量（Dummy Variable）又称哑变量、指标变量、二元变量，是取值为 0 或 1 的人工变量，用于将定性因素（如性别、地区、季节、政策实施）量化引入回归模型。

D = 1（具备某属性） 或  D = 0（不具备某属性）

虚拟变量使回归模型能够捕捉到定性因素对被解释变量的影响，是计量经济学处理非定量信息的基本工具。

2.1.2 虚拟变量的设置原则（核心考点）

单选判断简答
①
"N-1" 原则（避免完全多重共线性——虚拟变量陷阱）

如果一个定性因素有 m 个分类，则只能引入 m-1 个虚拟变量，否则会落入"虚拟变量陷阱"（Dummy Variable Trap）——即产生完全多重共线性，模型无法估计（X'X 不可逆）。

例：性别有男、女两类（m=2），只能设 1 个虚拟变量 D（如 D=1 表示女性，D=0 表示男性）。若同时引入 D男 和 D女，则 D男 + D女 = 1，与截距项完全共线。
②
基准组（Reference Group）选择

被省略的分类（取 0 的那一组）称为基准组/参照组。虚拟变量的系数解释为：该组与基准组之间被解释变量的平均差异。基准组的选择不影响模型的拟合优度，但影响系数解释的方便性。

③
互斥性与完备性

每个样本点只能且必须属于一个分类。互斥保证不重叠，完备保证无遗漏。

④
多种分类情景的处理

多个定性因素应分别引入各自的虚拟变量组。例如研究工资的影响因素，同时考虑性别（1个虚拟变量）和学历（本科/硕士/博士→2个虚拟变量），共引入 3 个虚拟变量。

2.1.3 虚拟变量的基本模型形式

单选判断简答
加法模型（截距改变）

Yi = β1 + β2Di + β3Xi + ui

D=0 时：E(Y|D=0) = β1 + β3X

D=1 时：E(Y|D=1) = (β1+β2) + β3X

β2 度量两组的截距差异（平均差异），斜率相同。（图解：两条平行线）

乘法模型（斜率改变）

Yi = β1 + β2Xi + β3(Di×Xi) + ui

D=0 时：E(Y|D=0) = β1 + β2X

D=1 时：E(Y|D=1) = β1 + (β2+β3)X

β3 度量两组斜率差异（边际效应差异）。（图解：两条交叉线）

加法+乘法模型（截距与斜率同时改变）

Yi = β1 + β2Di + β3Xi + β4(Di×Xi) + ui

β2 度量截距差异，β4 度量斜率差异。这是最灵活的设定，容许两组的回归线完全不同。

⚠️ 考试注意：单选题常问"加法模型与乘法模型的区别"——加法模型只改变截距（平行移动），乘法模型改变斜率（旋转），加乘并用同时改变两者。判断是否用加乘并用模型，取决于邹检验（Chow Test）的结果。

2.1.4 虚拟变量陷阱的数学本质

单选判断

设定性变量有 m 个分类，若引入全部 m 个虚拟变量 D1, D2, ..., Dm，则对每个样本点有：

D1 + D2 + ... + Dm = 1

在含有截距项的模型中，截距项对应一个元素全为 1 的列向量，恰好等于 m 个虚拟变量之和，因此产生完全多重共线性，设计矩阵 X 列秩小于列数，X'X 奇异，OLS 估计量不存在唯一解。

解决方式：要么去掉截距项（可引入全部 m 个虚拟变量），要么遵循 N-1 原则保留截距项。实务中几乎总是选择后者。

2.2.1 季节调整（Seasonal Adjustment）

单选判断简答

利用虚拟变量去除时间序列数据中的季节波动成分。季度数据设 3 个虚拟变量（Q2, Q3, Q4，以 Q1 为基准），月度数据设 11 个虚拟变量（以 1 月为基准）。

Yt = β1 + β2Q2t + β3Q3t + β4Q4t + β5Xt + ut

虚拟变量季节调整的优势：比移动平均法更灵活，可以同时控制其他经济变量的影响，且可直接检验季节效应的统计显著性。

2.2.2 分段回归与结构变化（Chow Test）

单选判断简答案例

邹检验（Chow Test, 1960）检验回归模型在两个（或多个）子样本间是否存在结构变化。虚拟变量法是邹检验的等价实现——引入截距虚拟变量和斜率虚拟变量（即交互项），联合检验这些虚拟变量的系数是否全为零。

邹检验步骤：

  1. 合并回归（有约束）：用全部样本估计 Y = β1 + β2X + u，得到 RSSR
  2. 分样本回归（无约束）：分别用子样本1和子样本2估计，得到 RSS1 和 RSS2，RSSUR = RSS1 + RSS2
  3. 构造 F 统计量：F = [(RSSR - RSSUR)/k] / [RSSUR/(N-2k)] ~ F(k, N-2k)，其中 k 为待估参数个数
  4. 判断：若 F > Fα(k, N-2k)，拒绝"结构稳定"原假设，认为存在结构变化
⚠️ 邹检验的前提假设：① 两个子样本的随机误差项独立同分布（同方差） ② 误差项服从正态分布 ③ 若违反同方差假设，应使用修正邹检验或虚拟变量交互项法（White 异方差稳健标准误）。

2.2.3 交互效应分析

单选判断案例

两个虚拟变量（或一个虚拟变量与一个连续变量）的交互项捕捉它们之间的协同效应。例如研究教育回报率是否因性别而异：

ln(Wage) = β1 + β2Female + β3Edu + β4(Female×Edu) + u

β4 度量女性与男性在教育回报率上的差异。若 β4 < 0 且显著，说明女性的教育回报率低于男性。

2.2.4 虚拟变量作为被解释变量（LPM 模型）

单选判断简答

线性概率模型（Linear Probability Model, LPM）：当被解释变量 Y 本身是二值变量（0/1）时，OLS 回归可解释为条件概率：

E(Y|X) = P(Y=1|X) = X'β

LPM 的缺陷：

  • 拟合值可能超出 [0,1] 范围（非概率约束）
  • 异方差性：Var(Y|X) = X'β·(1-X'β)，依赖于 X（需使用异方差稳健标准误）
  • 误差项非正态，非线性
  • 改进方法：Logit 或 Probit 模型（保证概率在 0-1 之间且非线性）

3.1 多重共线性的概念与分类

📝 题型覆盖 单选判断简答案例

3.1.1 定义

单选判断

多重共线性（Multicollinearity）指线性回归模型中，两个或多个解释变量之间存在高度（但不完全）相关或精确线性相关的现象。

经典线性回归模型（CLRM）假定：不存在完全多重共线性，即设计矩阵 X 列满秩 rank(X) = k+1（其中 k 为解释变量个数）。

3.1.2 完全多重共线性 vs 不完全多重共线性

单选判断简答
维度完全多重共线性不完全多重共线性
线性关系 存在精确线性关系：λ₁X₁ + λ₂X₂ + ... + λₖXₖ = 0（λ不全为0） 存在高度但不精确的相关关系：λ₁X₁ + λ₂X₂ + ... + λₖXₖ = v（v为随机误差）
矩阵秩 rank(X) < k+1，X'X 奇异 rank(X) = k+1，但 X'X 接近奇异
OLS 估计量 不存在唯一解（β̂ = (X'X)⁻¹X'Y 无法计算） 存在唯一解，但方差非常大
常见原因 虚拟变量陷阱、恒等式（如 X₁+X₂=总收入） 经济变量共同趋势（时间序列）、变量构造（X² 与 X）、小样本
解决方法 删除产生共线性的变量；重新设定模型 VIF 诊断后选择补救措施（见3.3）

3.1.3 多重共线性的来源

单选判断
  1. 经济变量共同的变动趋势：如时间序列数据中 GDP、消费、投资都随时间增长，高度相关
  2. 滞后变量的引入：Yt 与 Yt-1 通常高度相关
  3. 变量构造方式：模型同时包含 X 和 X²（多项式项），或 X 和 X/其他变量的比例
  4. 虚拟变量陷阱：违反 N-1 原则导致完全共线性
  5. 样本容量过小：小样本中变量间可能呈现虚假的相关关系
  6. 模型过度设定：包含大量无关或重复的解释变量

3.2 多重共线性的后果

📝 题型覆盖 单选判断简答
①

方差增大，估计精度下降

不完全多重共线性下，虽 β̂ 仍是 BLUE（最佳线性无偏估计量），但方差 Var(β̂ⱼ) 被方差膨胀因子（VIF）放大：

Var(β̂ⱼ) = σ² / [(1-Rⱼ²) · Σ(xᵢⱼ - x̄ⱼ)²] = [σ² / Σ(xᵢⱼ - x̄ⱼ)²] × VIFⱼ

其中 VIFⱼ = 1 / (1 - Rⱼ²)，Rⱼ² 为第 j 个解释变量对其他所有解释变量回归的拟合优度。

②

t 统计量变小，系数不显著

方差增大导致 t = β̂ⱼ / SE(β̂ⱼ) 变小，原本显著的变量可能变得不显著。这是多重共线性的典型症状：整体 F 检验显著但单个 t 检验不显著。

③

系数估计值不稳定，对模型设定敏感

β̂ 对微小数据变化（如增减一个观测值、增减一个变量）非常敏感。系数的符号可能不符合经济理论预期，且标准误很大。

④

完全共线性时 OLS 完全失效

X'X 不可逆，OLS 解不存在。但完全共线性是设定错误（如虚拟变量陷阱），而非随机问题，应通过修正模型设定解决。

⚠️ 特别注意：多重共线性不影响 OLS 的无偏性，也不影响模型的整体预测能力（R² 仍可很高）。它只影响个体系数的估计精度和统计推断。因此多重共线性本质上是"数据问题"而非"模型设定错误"——"毒药"的程度取决于研究目标。

3.3 多重共线性的诊断与补救措施

📝 题型覆盖 单选判断简答案例

3.3.1 诊断方法

单选判断简答
方法操作判断标准
相关系数矩阵 计算各解释变量间的 Pearson 相关系数 |r| > 0.8 提示可能存在严重共线性。但低相关系数不排除多重共线性（多个变量的线性组合相关）
方差膨胀因子（VIF） VIFⱼ = 1/(1-Rⱼ²)，其中 Rⱼ² 为 Xⱼ 对其他变量回归的 R² VIF > 10（或严格时 > 5）表示严重多重共线性。容忍度 Tolerance = 1/VIF < 0.1
特征根与条件指数（CI） 对 X'X 进行特征根分解，CI = √(λₘₐₓ / λₘᵢₙ) CI > 30 表示严重共线性；特征根值接近于 0 的个数指示共线性关系的数量
辅助回归法 分别以每个解释变量为被解释变量对其他变量做回归 若某个辅助回归的 F 统计量显著（R² 高），说明该变量与其他变量存在共线性
Klein 规则 比较辅助回归 R² 与整体模型 R² 若辅助回归 R² > 整体模型 R²，存在共线性问题

3.3.2 补救措施

单选判断简答案例
措施做法代价/局限
1. 删除变量 删除 VIF 最高的一个或多个变量 可能引发遗漏变量偏误（OVB），需在精度与偏误间权衡
2. 增加样本容量 收集更多数据 可降低方差但可能无法获得更多数据；新数据可能仍存在相同共线性结构
3. 变量变换 差分变换（ΔY, ΔX）、对数变换、比率变换（X₁/X₂）、标准化 差分可能丢失长期关系（协整）信息；比率变换可能产生解释困难
4. 主成分分析（PCA） 提取主成分替代原始变量 主成分的经济含义不直观，解释困难；损失部分信息
5. 岭回归（Ridge Regression） β̂(λ) = (X'X + λI)⁻¹X'Y，牺牲无偏性换取更小方差 引入偏误，λ 的选择具有主观性，推断困难（无标准误）
6. 逐步回归 向前/向后/逐步筛选变量 可能导致过度拟合，标准误被低估，模型选择偏误
7. 获取先验信息 利用经济理论对参数施加约束（如规模报酬不变） 先验信息可能不对，约束可能错误

4.1 异方差的定义、来源与后果

📝 题型覆盖 单选判断简答案例

4.1.1 异方差的定义

单选判断

异方差（Heteroscedasticity）指回归模型中随机误差项的方差不恒为常数，即 Var(uᵢ | Xᵢ) = σᵢ² ≠ σ²（常数）。

经典线性回归模型（CLRM）假定 同方差（Homoscedasticity）：Var(uᵢ | X) = σ²，∀ i。当该假定被违反时，即出现异方差问题。

H₀：Var(uᵢ) = σ²（同方差） vs  H₁：Var(uᵢ) ≠ σ²（异方差）

图示特征：同方差时残差散点图呈水平带状均匀分布；异方差时呈"喇叭形"（随 X 增大方差增大）、"漏斗形"（随 X 增大方差减小）或其他非均匀模式。

4.1.2 异方差的来源

单选判断
  1. 截面数据普遍存在：不同规模企业的行为差异——大企业的利润波动方差远大于小企业
  2. 学习效应：随时间推移，经济主体的行为方差可能减小（如生产经验积累使产品质量更稳定）
  3. 异常值（Outliers）：极端观测点的残差方差较大
  4. 模型设定偏误：遗漏重要变量或错误的函数形式可能引发异方差
  5. 数据采集技术改进：不同时期的数据质量差异导致方差变化
  6. 群组效应：不同组别的个体行为异质性导致方差不同（如不同国家的消费模式）

4.1.3 异方差的后果

单选判断简答案例
✅ 不影响
  • β̂ 的无偏性（仍满足 E(β̂|X) = β）
  • β̂ 的一致性（plim β̂ = β）
  • R² 的计算（仍可解释为解释平方和占比）
❌ 影响
  • β̂ 的有效性（Gauss-Markov 定理失效——OLS 不再是 BLUE。存在更有效的加权最小二乘法）
  • Var(β̂) 不再是标准公式（普通 OLS 标准误偏误，通常被低估）
  • t/F 检验失效（标准误偏误→t/F统计量偏误→推断不可靠）
  • 预测区间不准确（基于同方差假设计算的置信区间过宽或过窄）
⚠️ 考试重点：异方差下的 OLS 仍然是无偏且一致的，但不是有效的。标准误的偏误方向取决于异方差的形式——多数情况下 OLS 标准误被低估（t 值偏高，更容易"显著"），但也不排除被高估的可能。

4.2 异方差的诊断方法

📝 题型覆盖 单选判断简答案例

4.2.1 图示法（Graphical Method）

单选判断

绘制 残差 û 对拟合值 Ŷ 的散点图或 残差² 对某个解释变量 X 的散点图。若散点呈随机均匀分布 → 同方差；若呈明显的模式（如喇叭形）→ 异方差。

优点：直观、初步判断。缺点：主观性强，无法给出统计显著性判断。

4.2.2 布雷-帕甘检验（Breusch-Pagan Test, 1979）

单选判断简答

思想：检验残差平方 û² 是否可以用解释变量（或其子集）Z 来解释。

步骤：

  1. OLS 估计原模型，获得残差 ûᵢ
  2. 构造辅助回归：ûᵢ² = α₀ + α₁Z₁ᵢ + α₂Z₂ᵢ + ... + αₚZₚᵢ + vᵢ
  3. LM = n·R²aux ~ χ²(p)（H₀：所有 α = 0，即同方差）
  4. 若 LM > χ²α(p)，拒绝同方差原假设。

特点：检验的势依赖于 Z 的选择。若已知异方差与哪些变量有关，BP 检验的效力更高。

4.2.3 怀特检验（White Test, 1980）

单选判断简答案例

思想：BP 检验的推广——辅助回归包含解释变量、平方项和交叉乘积项，不依赖异方差的具体形式（一般性检验）。

辅助回归：û² = δ₀ + δ₁X₁ + δ₂X₂ + ... + δₖXₖ + δ₁₁X₁² + δ₂₂X₂² + ... + δₖₖXₖ² + δ₁₂X₁X₂ + ... + v

LM = n·R²aux ~ χ²(df)，df 为辅助回归中除截距外的参数个数。

优点：不指定异方差形式；缺点：自由度损失大（变量多时辅助回归参数过多），小样本检验势低。

SAS/STATA 常用：White 检验（含交叉项）或 White 简化检验（仅含变量和平方项）。

4.2.4 戈德菲尔德-匡特检验（Goldfeld-Quandt Test, 1965）

单选判断简答

适用于单一变量引起异方差且可排序的情形（如异方差随某一解释变量 X 单调变化）。

步骤：

  1. 按照假设的异方差来源变量 X 对样本排序
  2. 删除中间 c 个观测（通常 c ≈ n/4）
  3. 分别对前 m 个（小方差组）和后 m 个（大方差组）做 OLS 回归
  4. F = RSS₂/RSS₁ ~ F(m-k-1, m-k-1)，若 F > Fα，拒绝同方差

特点：适用面窄（需已知异方差来源且假设单调变化），但较直观。

4.2.5 帕克检验（Park Test）与格莱泽检验（Glejser Test）

单选判断
检验辅助回归形式特点
Park 检验ln(û²) = α + β·ln(X) + v假设异方差为幂函数形式；对函数设定较敏感
Glejser 检验|û| = α + β·X^h + v（h=±1, ±0.5, ±2 等）检验残差绝对值与 X 的关系；可尝试多种幂次

4.3 异方差的补救措施

📝 题型覆盖 单选判断简答案例

4.3.1 加权最小二乘法（Weighted Least Squares, WLS）

单选判断简答

思想：对方差大的观测赋较小的权重，方差小的观测赋较大的权重，实现加权同方差。

若已知 Var(uᵢ) = σ²·wᵢ（wᵢ 已知），则变换后的模型为：

Yᵢ/√wᵢ = β₁/√wᵢ + β₂X₂ᵢ/√wᵢ + ... + βₖXₖᵢ/√wᵢ + uᵢ/√wᵢ

变换后误差项 Var(uᵢ/√wᵢ) = σ²（常数），满足同方差假定。

权重 wᵢ 的确定：

  • 若已知异方差与 X 成正比：Var(uᵢ) ∝ Xᵢ → wᵢ = Xᵢ
  • 若已知异方差与 X² 成正比：Var(uᵢ) ∝ Xᵢ² → wᵢ = Xᵢ²
  • 可行 WLS（FGLS）：先用 OLS 估计，用残差平方估计方差函数，再以估计的权重进行 WLS

局限：权重必须正确设定，否则 WLS 可能比 OLS 更差（权重指定错误导致有偏）。

4.3.2 异方差稳健标准误（White/Huber Sandwich Estimator）

单选判断简答案例

思想：不修正异方差本身，而是修正标准误的估计，使推断（t 统计量、置信区间）在异方差下仍然有效。

Var̂(β̂) = (X'X)⁻¹ X' diag(ûᵢ²) X (X'X)⁻¹

即"三明治估计量"（Sandwich Estimator）。

优点：

  • 无需假设异方差的具体形式（异方差一致估计量）
  • 在大样本下提供正确的标准误，t/F 推断有效
  • STATA 中只需加 , robust 选项即可实现

局限：

  • 小样本下稳健标准误可能有偏（HC1、HC2、HC3 等修正版本可改善小样本表现）
  • 效率不及 WLS（若方差函数正确设定）
⚠️ 考试重点：异方差稳健标准误是目前最常用的补救方法——简单、通用、可靠。WLS 在方差函数已知时才更优。考试中遇到"如何应对异方差"的问题，稳健标准误是首选答案。

4.3.3 变量变换法

单选判断

对数变换：对变量取对数 ln(Y) 或 ln(X) 通常能压缩方差的比例效应，缓解异方差。适用于方差与变量水平值成比例的情形。

Box-Cox 变换：更一般的幂变换族，通过数据自适应地选择变换参数。

异方差 vs 自相关 异方差：误差方差在观测之间不同（Var(uᵢ) ≠ Var(uⱼ)），常见于截面数据 自相关：误差在不同观测之间相关（Cov(uᵢ,uⱼ) ≠ 0），常见于时间序列数据

5.1 自相关的定义、来源与后果

📝 题型覆盖 单选判断简答案例

5.1.1 自相关的定义

单选判断

自相关（Autocorrelation/Serial Correlation）指线性回归模型中，不同观测期的随机误差项之间存在相关性：

Cov(uᵢ, uⱼ) ≠ 0   对 i ≠ j

经典线性回归模型（CLRM）假定 无自相关：Cov(uᵢ, uⱼ) = 0，∀ i ≠ j。当该假定被违反时，即出现自相关问题。

最常用的一阶自回归模型 AR(1)：

uₜ = ρ·uₜ₋₁ + εₜ   其中 |ρ| < 1，εₜ ~ iid(0, σ²ε)

ρ 为自回归系数：ρ > 0 → 正自相关（最常见），ρ < 0 → 负自相关（少见）。

5.1.2 自相关的来源

单选判断
  1. 时间序列数据的内在惯性：经济变量（GDP、消费、就业）通常具有记忆性——当期冲击会延续到以后各期。这是最常见的来源。
  2. 模型设定偏误：
    • 遗漏变量：遗漏了具有自相关性的重要解释变量（如趋势变量）
    • 错误函数形式：如应取对数而没取对数，应加平方项而没加
  3. 数据加工处理：移动平均、插值、季节调整等操作可能人为引入自相关结构
  4. 蛛网现象：农业供给对价格反应的滞后（当期价格影响下期供给，导致误差项自相关）
  5. 空间自相关：相邻地区的经济变量相互影响（跨区域溢出效应）

5.1.3 自相关的后果

单选判断简答案例
✅ 不影响
  • β̂ 的无偏性（仍满足 E(β̂|X) = β）
  • β̂ 的一致性（若 |Xₜ| 有界且 E(Xₜuₜ)=0）
❌ 影响
  • β̂ 的有效性（OLS 不再是 BLUE——存在更有效的 GLS 估计量）
  • 标准误被低估（正自相关下 OLS 标准误偏小，t 值偏大——虚假显著性）
  • t/F 检验失效——标准误偏误导致推断不可靠
  • R² 被高估（拟合优度看起来比实际好，因为相邻观测相似）
  • 预测不准确：基于过去预测未来的置信区间不可靠
⚠️ 考试重点：正自相关下，OLS 标准误通常被低估（低估标准误 → 高估 t 值 → 更容易拒绝 H₀ → 虚假显著性）。这与异方差不同（异方差下标准误方向不确定）。此外，R² 和 F 统计量也倾向于被高估，整体模型表现"看起来好于实际"。

5.2 自相关的诊断方法

📝 题型覆盖 单选判断简答案例

5.2.1 图示法

单选判断

绘制 残差 ûₜ 对时间 t 的序时图（Time Series Plot）：正自相关时残差呈连续同号的"波浪"模式；负自相关时残差呈频繁交替正负的"锯齿"模式。

绘制 ûₜ 对 ûₜ₋₁ 的散点图：呈正斜率的线性模式 → 正自相关；呈负斜率 → 负自相关。

5.2.2 德宾-沃森检验（Durbin-Watson Test, 1950, 1951）

单选判断简答案例

DW 统计量：

d = Σ(ûₜ - ûₜ₋₁)² / Σûₜ²

d 的取值范围为 [0, 4]：

  • d ≈ 2 → 无自相关（d=2 对应 ρ=0）
  • d → 0 → 正自相关（d=0 对应 ρ=+1）
  • d → 4 → 负自相关（d=4 对应 ρ=-1）

判断规则：

0 → dL → 不确定区 → dU → 2 → 4-dU → 不确定区 → 4-dL → 4

（正自相关）   （无自相关）   （负自相关）

DW 检验的局限：

  • 仅检验 AR(1) 过程（一阶自回归），无法检验高阶自相关
  • 存在不确定区域（无法判断）
  • 模型含有滞后被解释变量时 DW 统计量趋于 2（有偏），无效
  • 需要截距项，且样本量不能太小

德宾 h 检验（Durbin h-test）：当模型包含 Yₜ₋₁ 作为解释变量时，DW 检验失效，改用 h 统计量：h = (1 - d/2)·√[N/(1 - N·Var̂(β̂Yₜ₋₁))] ~ N(0,1)。

5.2.3 布罗施-戈弗雷检验（Breusch-Godfrey LM Test, 1978）

单选判断简答案例

思想：检验残差是否存在高阶自相关（AR(p) 或 MA(q)）。不要求解释变量严格外生，可包含滞后被解释变量。

步骤：

  1. OLS 估计原模型，获得残差 ûₜ
  2. 辅助回归：ûₜ = Xₜ'γ + α₁ûₜ₋₁ + α₂ûₜ₋₂ + ... + αₚûₜ₋ₚ + vₜ
  3. LM = (n-p)·R²aux ~ χ²(p)（H₀：α₁=α₂=...=αₚ=0，即无自相关）

优点：① 可检验任意阶自相关 ② 可包含滞后被解释变量 ③ 可检验移动平均（MA）过程 ④ 是 DW 检验的一般化推广。

5.2.4 相关系数图（ACF/PACF）与 Q 统计量

单选判断

自相关函数（ACF）：计算残差各阶滞后自相关系数 rₖ，绘制条形图。若所有 rₖ 都很小（在 2/√N 范围内），说明无自相关。

偏自相关函数（PACF）：在控制中间阶滞后后计算各阶偏自相关。AR(p) 的 PACF 在滞后 p 处截尾。

Ljung-Box Q 统计量：Q = N(N+2)·Σₖ₌₁ᵐ rₖ²/(N-k) ~ χ²(m)，联合检验前 m 个自相关系数是否全为零。

5.3 自相关的补救措施

📝 题型覆盖 单选判断简答案例

5.3.1 广义差分法（Generalized Difference）

单选判断简答案例

AR(1) 情形的广义差分（ρ 已知时）：

Yₜ - ρYₜ₋₁ = β₁(1-ρ) + β₂(Xₜ - ρXₜ₋₁) + εₜ

变换后的模型满足 CLRM 假定（εₜ iid），OLS 估计有效。

ρ 未知时的处理方法：

① 科克伦-奥克特迭代法（Cochrane-Orcutt, 1949）

Step 1: OLS 获得残差 ûₜ → Step 2: ûₜ 对 ûₜ₋₁ 回归得 ρ̂ → Step 3: 用 ρ̂ 做广义差分 → Step 4: 重复 2-3 直至 ρ̂ 收敛。

② 普莱斯-温斯滕法（Prais-Winsten, 1954）

与 C-O 类似，但保留第一个观测值（C-O 丢掉第一个观测）。Prais-Winsten 对第一个观测作变换：Y₁√(1-ρ²), X₁√(1-ρ²)，在小样本中更有效。

③ 德宾两步法（Durbin's Two-Step Method）

Step 1: 将 Yₜ 对 Xₜ、Xₜ₋₁、Yₜ₋₁ 回归得 Yₜ₋₁ 的系数作为 ρ 的一致估计 → Step 2: 用该 ρ̂ 做广义差分。

④ 一阶差分法（First Difference）

当 ρ ≈ 1 时（如随机游走），直接取一阶差分：ΔYₜ = β₂ΔXₜ + Δuₜ。这是最简单的方法，但以丢失长期关系信息为代价。

5.3.2 纽维-韦斯特 HAC 标准误（Newey-West HAC Estimator, 1987）

单选判断简答案例

思想：与异方差稳健标准误类似的"三明治"思想——在估计标准误时同时考虑异方差和自相关，得到HAC（Heteroscedasticity and Autocorrelation Consistent）标准误。

Var̂HAC(β̂) = (X'X)⁻¹ X' Σ̂ X (X'X)⁻¹

其中 Σ̂ 是经过核函数加权的误差协方差矩阵估计量，对各阶自相关赋予递减的权重。

优点：不需要估计自相关参数 ρ，适用于大样本，对异方差和自相关同时稳健。

局限：需要选择带宽（lag truncation）参数——常用：bandwidth = 0.75·N¹ᐟ³。

STATA 实现： newey Y X1 X2, lag(3) 或 OLS 后加 , vce(hac nwest)。

5.3.3 可行的广义最小二乘法（FGLS）

单选判断简答

用数据估计自相关参数 ρ 后再进行 GLS 变换。C-O 迭代法和 Prais-Winsten 法都属于 FGLS 范畴。FGLS 比 OLS 更有效，但小样本下有偏（因为 ρ̂ 不是 ρ 的无偏估计）。

⚠️ 策略选择：大样本下（N>100）→ HAC 标准误（简单、稳健、不需要建模自相关结构）；小样本下 → FGLS（Prais-Winsten 或 C-O 迭代）更有效。若 ρ 接近 1 → 一阶差分法。务必先检查模型设定——许多"自相关"实际上是遗漏变量或错误函数形式的信号。

专题6：F检验与回归显著性检验（F-Test）

联合显著性检验 · 模型整体检验 · 约束检验 · Chow检验 · 方差分析

★★★★★
考试权重：18~22分 │ 选择4~6分 · 计算6~8分 · 案例分析6~8分
  • F统计量核心公式：F = (RSSr−RSSur)/q ÷ RSSur/(n−k−1) ~ F(q, n−k−1)
  • F与R²的关系：F = (R²ur−R²r)/q ÷ (1−R²ur)/(n−k−1)
  • 整体F检验：H₀: β₁=β₂=...=βk=0，F = R²/k ÷ (1−R²)/(n−k−1)
  • F > Fα(q, n−k−1) → 拒绝H₀ —— F越大越显著
  • F < 1 说明模型几乎没有解释力（R²接近0）

1. F检验的基本原理

选择题 简答题 教师原题

F检验用于检验多个线性约束是否同时成立（联合显著性检验）。核心思想是比较有约束模型（RSSr）和无约束模型（RSSur）的残差平方和：若约束成立，两者差异小；若约束不成立，约束模型残差大幅增加。

F统计量（一般形式）：
F = (RSSr − RSSur) / q  ÷  RSSur / (n − k − 1)  ∼  F(q, n−k−1)

其中 q = 约束个数，k = 无约束模型自变量个数，n = 样本量。

基于R²的等价形式：
F = (R²ur − R²r) / q  ÷  (1 − R²ur) / (n − k − 1)
💡 直觉理解：F统计量度量"由于施加约束而增加的残差"相对于"模型本身的残差"有多大。如果约束是真的，这个比值应该接近1（服从F分布）；如果约束是假的，分子远大于分母，F值很大。

2. 模型整体显著性F检验

选择题 计算题 教师原题

这是最常用的F检验——检验所有斜率系数是否联合显著（即模型是否有解释力）：

整体F检验：
H₀: β₁ = β₂ = ... = βk = 0   （所有自变量联合不显著）
F = R²/k  ÷  (1−R²)/(n−k−1)  ∼  F(k, n−k−1)

约束模型是仅含截距项的回归（R²r=0，RSSr=SST）。

⚠️ 注意区别：整体F检验 ≠ 每个系数的t检验。有可能整体F显著（联合显著）但个别t不显著（存在多重共线性时常见）。也有可能整体F不显著但某个t显著（罕见）。

3. 一般线性约束的F检验

计算题 简答题 教师原题

F检验可处理各类线性约束，包括：

  • 排除性约束：一组变量的系数全为0（最常见，如H₀: β₃=β₄=β₅=0）
  • 等式约束：两个系数相等（如H₀: β₂=β₃）
  • 线性组合约束：如H₀: β₁+β₂=1（Cobb-Douglas生产函数的规模报酬不变检验）
等式约束示例（检验H₀: β₂=β₃）：
无约束：y = β₀ + β₁x₁ + β₂x₂ + β₃x₃ + u
施加β₂=β₃后：y = β₀ + β₁x₁ + β₂(x₂+x₃) + u  （构造新变量 z = x₂+x₃）

4. Chow检验 — 结构变化检验

选择题 分析题 教师原题

Chow检验是F检验在结构变化（断点）检验中的特例，用于判断两个子样本的回归系数是否相同（如2008年金融危机前后、政策实施前后）。

Chow检验F统计量：
F = [RSSp − (RSS1+RSS2)] / (k+1)  ÷  (RSS1+RSS2) / (n−2k−2)
~ F(k+1, n−2k−2)

RSSp=合并样本残差，RSS1=子样本1残差，RSS2=子样本2残差，n=n₁+n₂。

💡 使用前提：① 两个子样本各自独立可估计 ② 误差方差相同（同方差假设） ③ 断点位置已知。若误差方差不同，需用修正的Wald检验替代。

📋 案例：工资决定方程的联合显著性检验

现考虑以下假设检验场景：

专题7：随机误差项与残差（Error Term vs Residual）

概念辨析 · 性质差异 · 在OLS假设中的角色 · 诊断应用

★★★☆☆
考试权重：8~12分 │ 选择2~4分 · 简答4~6分 · 判断2分
  • 误差项 uᵢ = 总体回归中真实值偏离条件期望的部分，不可观测
  • 残差 ûᵢ = 样本回归中观测值偏离拟合值的部分，可计算
  • 核心关系：残差是误差项的样本估计——ûᵢ = yᵢ − ŷᵢ
  • OLS使得 Σûᵢ=0 且 Σxᵢûᵢ=0（样本矩条件），但误差项 uᵢ 并不满足这些性质
  • 残差用于诊断：异方差检验（BP检验、White检验）、自相关检验（DW检验）、正态性检验

1. 概念辨析

选择题 简答题 教师原题

误差项 (Error Term) uᵢ：在总体模型 yᵢ = β₀ + β₁xᵢ + uᵢ 中，uᵢ 代表所有未被xᵢ解释的因素（遗漏变量、测量误差、函数形式误设等）。它是总体的、不可观测的随机变量。

残差 (Residual) ûᵢ：在样本回归 ŷᵢ = β̂₀ + β̂₁xᵢ 中，ûᵢ = yᵢ − ŷᵢ。它是样本的、可计算的数值。

专题8：Probit与Logit模型（Binary Choice Models）

⚠️ 考试权重提示：本专题考试权重极低（约2-4分），建议优先学完核心专题(1/2/4/5/6/9/11/12)后再回看。若时间紧迫，可直接跳到考前速记部分。

二元选择模型 · 潜变量框架 · 边际效应 · 拟合优度

★★☆☆☆
考试权重：4~6分 │ 选择2分 · 简答2~4分 · 不考计算
  • 二元选择模型：被解释变量y∈{0,1}（是/否、参与/不参与）
  • 潜变量框架：y* = xβ + u，y = 1[y* > 0]
  • Probit：u ~ N(0,1) → P(y=1|x) = Φ(xβ)
  • Logit：u ~ Logistic → P(y=1|x) = Λ(xβ) = e^{xβ}/(1+e^{xβ})
  • 系数不能直接解释大小——只看符号和显著性
  • 边际效应 = ∂P/∂xj = f(xβ)·βj（f是密度函数）
  • 拟合优度：McFadden R² = 1 − lnLur/lnLr

1. 为什么不能用OLS估计二元选择模型

选择题 简答题
线性概率模型（LPM）的三大问题：
  • 预测值越界：ŷ可能小于0或大于1（概率必须在[0,1]区间）
  • 异方差性：Var(y|x) = P(x)(1−P(x))，依赖于x，必然异方差
  • 线性假设不合理：概率变化在极端值时边际效应应趋近于0（S形曲线），但LPM假设恒定边际效应

选择题 简答题 教师原题
边际效应：
∂P(y=1|x) / ∂xj = f(xβ) · βj
其中 f(·) 为密度函数（Probit: φ(·)；Logit: Λ(·)[1−Λ(·)]）

两种常用报告方式：

  • 平均边际效应 (AME)：对每个观测计算边际效应后取均值
  • 均值处边际效应 (MEM)：在x̄处计算边际效应
💡 解读规则：Probit/Logit系数只报告符号和显著性，不报告数值大小。解释时用边际效应！例如"教育年限增加1年，参与劳动的概率平均增加3.2个百分点"。

2. Gauss-Markov定理

选择题 简答题 教师原题
核心定理：在MLR.1~MLR.5（线性、随机抽样、无完全共线性、外生性、同方差）下，OLS估计量 β̂ 是所有线性无偏估计量中方差最小的——即 BLUE（Best Linear Unbiased Estimator）。

定理的四个条件缺一不可：

  • Best（最优）：方差最小——来自同方差性MLR.5
  • Linear（线性）：β̂是y的线性函数——来自线性模型MLR.1
  • Unbiased（无偏）：E(β̂)=β——来自外生性MLR.4
  • Estimator（估计量）：可计算的统计量
β̂的方差（MLR.1~MLR.5下）：
Var(β̂j|X) = σ² / [SSTj·(1−R²j)]
其中 SSTj = Σ(xij−x̄j)²，R²j = xj对其他自变量回归的R²

3. 假设违背的诊断与修正

3.1 外生性违反（内生性）

简答题 分析题 教师原题
  • 原因：遗漏变量、测量误差、反向因果（联立性）
  • 后果：OLS有偏且不一致（最严重，不可通过增大样本解决）
  • 补救：工具变量法（IV/2SLS）、面板数据固定效应、自然实验/DID

3.2 异方差性

选择题 计算题 教师原题
  • 后果：OLS无偏但非有效（不是BLUE），标准误偏误，t/F检验失效
  • 诊断：BP检验（Breusch-Pagan）、White检验、残差vs拟合值散点图
  • 补救：① 稳健标准误（Huber-White sandwich estimator）② WLS（加权最小二乘）③ 变量变换（如取对数）
BP检验统计量：
LM = n·R²û² ∼ χ²q  （残差平方对自变量回归）
White检验：检验更一般的形式（含交叉项和平方项），LM = n·R²û²

3.3 自相关（序列相关）

选择题 计算题
  • 常见于：时间序列数据、面板数据
  • 后果：与异方差类似——无偏但非有效，标准误偏误
  • 诊断：DW检验（Durbin-Watson）、残差ACF图
  • 补救：① Newey-West标准误（HAC）② 广义最小二乘（GLS/ Cochrane-Orcutt）③ 差分模型
DW统计量：
DW = Σ(ût−ût−1)² / Σût² ≈ 2(1−ρ̂)   （ρ̂为一阶自相关系数）
DW≈2 → 无自相关；DW<dL → 正自相关；DW>4−dL → 负自相关

3.4 多重共线性

选择题 简答题
  • 本质：自变量之间高度相关（但不是完全共线性）
  • 后果：OLS仍无偏，但方差很大（系数估计不精确），t值变小
  • 诊断：VIF = 1/(1−R²j)，VIF>10为严重

(1) 逐一判断每个OLS假设是否可能被违反，并说明理由；

(2) White检验结果说明什么？如何补救？

(1)

  • MLR.1（线性）：Ramsey RESET p=0.063 > 0.05，在5%水平不能拒绝线性假设，模型设定基本合理
  • MLR.2（随机抽样）：横截面数据若按简单随机抽样收集，基本满足
  • MLR.3（无完全共线性）：VIF最高8.51 < 10，没有完全共线性，可估计。但exper和exper²高度相关（VIF接近10），需要注意

  • MLR.5（同方差）：White检验p<0.001，强烈拒绝同方差假设

📝 原题：异方差下的OLS性质

如果回归模型存在异方差（Var(uᵢ|xᵢ) = σ²·xᵢ²），但其他OLS假设均满足：

(1) OLS估计量是否仍然无偏？为什么？

(2) OLS估计量是否仍然是BLUE？为什么？

(3) 通常报告的t统计量是否可靠？如何修正？

✅ 解答：

(1) 仍然无偏。无偏性只依赖MLR.4（E(u|X)=0），不依赖同方差假设。证明：E(β̂|X) = β + (X'X)⁻¹X'E(u|X) = β。

(2) 不是BLUE。BLUE需要MLR.1~MLR.5都成立。异方差下，虽然OLS仍线性无偏，但存在其他线性无偏估计量（如WLS）方差更小。Var(β̂OLS) ≠ σ²(X'X)⁻¹。

(3) 不可靠。通常报告的t统计量用了错误的方差估计。应使用White/Huber稳健标准误修正。在Stata中用reg y x, robust；在R中用coeftest(model, vcov=vcovHC)。

📝 原题：Gauss-Markov定理的条件

判断以下说法是否正确并说明理由：\"只要样本量足够大，即使E(u|X)≠0，OLS估计量也是一致的\"。

✅ 解答：

错误。OLS的一致性需要两个条件：① E(X'u)=0（正交条件）② rank(X'X)→∞。当E(u|X)≠0时，必然有E(X'u)≠0（因为E(X'u)=E[E(X'u|X)]=E[X'E(u|X)]），正交条件不成立，所以即使n→∞，β̂也不收敛到β。

💡 大样本能解决的问题：异方差、非正态性。大样本不能解决的问题：内生性（遗漏变量、反向因果、测量误差）。

KP-10.1 内生性根源 理论 简答 — 遗漏变量偏差、测量误差、联立因果。当 Cov(x, ε) ≠ 0 时 OLS 有偏且不一致。

专题11：面板数据模型（Panel Data）

Panel Data Models — Fixed Effects · Random Effects · Dynamic Panel

📌 PRIORITY: CORE 📊 WEIGHT: 20% ⭐⭐⭐⭐ 📖 FE · RE · Hausman · 差分GMM

📌 核心知识点 理论 计算 案例 论述

KP-11.1 面板数据结构与优势 理论 简答 — 截面 N × 时期 T 的二维数据。优势：控制不可观测异质性、提供更多变异、减少共线性、可研究动态调整。

KP-11.2 混合OLS (Pooled OLS) 理论 判断 — 忽略个体异质性：yᵢₜ = xᵢₜβ + uᵢₜ。若存在个体效应 Cov(xᵢₜ, αᵢ) ≠ 0 则估计不一致。

KP-11.3 固定效应模型 (FE) 理论 计算 论述 — yᵢₜ = xᵢₜβ + αᵢ + εᵢₜ。组内变换（within transformation）消去 αᵢ。允许 αᵢ 与 xᵢₜ 相关。不随时间变化的变量（性别、种族）被消去。

KP-11.4 随机效应模型 (RE) 理论 计算 — yᵢₜ = xᵢₜβ + αᵢ + εᵢₜ，假设 αᵢ ~ iid(0, σ²_α) 且 αᵢ ⊥ xᵢₜ。FGLS 估计。若假设成立，RE 比 FE 更有效。

KP-11.5 Hausman 检验 理论 计算 论述 — H₀: RE 一致且有效，FE 一致但低效。H = (β̂_FE − β̂_RE)'[Var(β̂_FE)−Var(β̂_RE)]⁻¹(β̂_FE − β̂_RE) ~ χ²(K)。p < 0.05 拒绝 RE。

KP-11.6 组内 R² / 组间 R² / 总体 R² 理论 计算 — Within R² = Corr(yᵢₜ−ȳᵢ, (xᵢₜ−x̄ᵢ)β̂)²。用于 FE 模型拟合优度评价。

KP-11.7 一阶差分法 (FD) 理论 计算 — Δyᵢₜ = Δxᵢₜβ + Δεᵢₜ。消去个体效应。T=2 时 FE = FD；T>2 时 FE 更有效（若 εᵢₜ 为 iid）。

KP-11.8 动态面板与差分GMM 理论 计算 案例 — yᵢₜ = ρyᵢₜ₋₁ + xᵢₜβ + αᵢ + εᵢₜ。FE 估计有偏（Nickell bias），N→大时偏误渐消。Arellano-Bond (1991) 差分GMM：用 Δyᵢₜ₋₂, Δyᵢₜ₋₃,… 作为 Δyᵢₜ₋₁ 的工具变量。

KP-11.9 系统GMM 理论 案例 — Blundell-Bond (1998)：同时使用水平方程和差分方程，用滞后水平值作为差分方程的工具变量，差分值作为水平方程的工具变量。适用于持久性序列。

📌 核心知识点 理论 计算 案例 论述

KP-12.1 平稳性定义 理论 简答 判断 — 严平稳：联合分布不随平移改变。弱平稳（协方差平稳）：E(yₜ)=μ, Var(yₜ)=γ₀, Cov(yₜ,yₜ₋ₖ)=γₖ 与 t 无关。

KP-12.2 单位根检验 (ADF / PP / KPSS) 理论 计算 论述 — ADF 检验：H₀: 存在单位根（非平稳）。Δyₜ = α + βt + γyₜ₋₁ + ΣδᵢΔyₜ₋ᵢ + εₜ。γ=0 不能拒绝 H₀ 即存在单位根。McKinnon 临界值。

KP-12.3 ARIMA(p,d,q) 模型 理论 计算 案例 — AR(p): yₜ = c + φ₁yₜ₋₁+…+φₚyₜ₋ₚ + εₜ。MA(q): yₜ = μ + εₜ+θ₁εₜ₋₁+…+θ₉εₜ₋₉。ARIMA: 先差分 d 次使序列平稳，再拟合 ARMA(p,q)。

KP-12.4 Box-Jenkins 建模流程 理论 简答 — (1) 识别：ACF/PACF 定阶；(2) 估计：MLE/OLS；(3) 诊断：残差白噪声检验（Ljung-Box Q）；(4) 预测。

KP-12.5 ACF 与 PACF 理论 计算 — ACF：自相关函数 ρₖ = Cov(yₜ,yₜ₋ₖ)/Var(yₜ)。PACF：偏自相关函数，剔除了中间滞后项的影响。AR(p)的PACF在p阶后截尾；MA(q)的ACF在q阶后截尾。

KP-12.6 伪回归问题 理论 简答 判断 — 两个独立非平稳序列回归可得显著 t 统计量（Granger-Newbold 现象）。R² > DW 是伪回归信号。必须用协整方法处理。

KP-12.7 协整 (Cointegration) 理论 计算 案例 — 若 yₜ, xₜ ~ I(1)，存在线性组合 uₜ = yₜ − βxₜ ~ I(0)，则称 yₜ 与 xₜ 协整。Engle-Granger 两步法：协整回归→残差ADF检验。Johansen 协整检验（VAR框架）。

KP-12.8 误差修正模型 (ECM) 理论 计算 论述 — Δyₜ = α + βΔxₜ + λ·ECₜ₋₁ + εₜ，其中 ECₜ₋₁ = yₜ₋₁ − γxₜ₋₁。λ < 0 为误差修正速度，λ取值在 (−1,0) 之间。

KP-12.9 格兰杰因果关系 理论 计算 论述 — Granger 因果：如果 X 的过去值有助于预测 Y（在包含Y的过去值的前提下），则 X Granger 引起 Y。基于 VAR 的 F 检验。注意：Granger 因果 ≠ 真正因果。

KP-12.10 VAR 与 结构VAR 理论 案例 — VAR(p): Yₜ = c + Π₁Yₜ₋₁+…+ΠₚYₜ₋ₚ + εₜ。SVAR 通过 Cholesky 分解/短期约束/长期约束识别结构性冲击。脉冲响应函数（IRF）和方差分解（FEVD）。

KP-13.1 模型设定偏误 (Specification Error) 理论 简答 — 遗漏相关变量（偏误）、包含无关变量（低效但无偏）、错误函数形式（偏误）、测量误差（衰减偏误）。

KP-13.2 RESET 检验 (Regression Specification Error Test) 理论 计算 — Ramsey RESET：在原模型中加入拟合值的平方项/立方项，检验其联合显著性。H₀: 模型设定正确。F~F(q, N−K−q)。

KP-13.3 多重共线性 (Multicollinearity) 理论 判断 简答 — 方差膨胀因子 VIF = 1/(1−R²ⱼ)。VIF > 10 或 1/VIF < 0.1 提示严重共线性。后果：标准误膨胀、系数不稳定，但估计仍无偏且一致。

KP-13.4 异方差 (Heteroskedasticity) 理论 计算 — Var(εᵢ|X) ≠ σ²。OLS 仍无偏但标准误有偏。Breusch-Pagan 检验（H₀: 同方差）、White 检验（更一般）。补救：异方差稳健标准误 (White/Huber-Eicker-Sandwich) 或 WLS/FGLS。

KP-13.5 自相关 (Autocorrelation / Serial Correlation) 理论 计算 — Cov(εₜ, εₛ) ≠ 0 (t≠s)。Durbin-Watson 检验 (H₀: ρ=0，仅一阶自相关)。Breusch-Godfrey LM 检验（高阶）。补救：Newey-West 标准误/Cochrane-Orcutt/Prais-Winsten。

KP-13.6 参数稳定性检验 理论 计算 — Chow 检验（已知断点）：比较分段与全样本残差平方和。CUSUM 检验（未知断点）：递归残差累积和。Quandt-Andrews 检验（未知断点）。

KP-13.7 非正态性检验 理论 判断 — Jarque-Bera (JB) 检验：H₀: ε~N。JB = (N/6)·[S²+(K−3)²/4] ~ χ²(2)。S=偏度，K=峰度。大样本渐近有效。

Durbin-Watson Breusch-Godfrey LM DW：仅一阶自相关，有"不确定区域"，滞后因变量模型无效。BG：任意阶自相关，含滞后因变量仍然有效，使用辅助回归R²。
Chow 检验 CUSUM 检验 Chow：需已知断点位置，比较子样本的 RSS。CUSUM：无需已知断点，基于递归残差的累积和，可用于检测结构突变的时序。
⚠️ 易错：VIF > 10 = 一定需要处理？—— 如果共线性变量仅是控制变量，不感兴趣的预测变量存在共线性不影响预测精度，可以不处理。但如果感兴趣的变量VIF高，则需要考虑岭回归/主成分/删除变量。
⚠️ 易错：RESET检验不显著 = 模型设定正确？—— RESET仅能检测特定类型的设定偏误（非线性/遗漏交互项），不能检测所有设定问题。且RESET不能告知具体问题类型。
